# Skyloom

**Draw a word. Weave a world.**
抽取一個詞，編織一個世界。

Skyloom 是一個以天空為靈感的詞彙抽牌工具，適合寫作、繪畫、漫畫、OC／CP 與各種自由創作。從日常詞彙出發，抽取一個詞，編織一個世界。

本版使用 `everyday_prompt_bank_v3_zh_tw.json`，收錄 21 個分類、840 個繁體中文詞彙。保留單詞最愛、牌組收藏、分類收藏與抽牌紀錄功能。使用純 HTML、CSS 與 JavaScript，無須安裝套件或建立帳號。

## 開始使用

1. 下載專案並解壓縮，保留 JSON、HTML、CSS 與 JavaScript 檔案的相對位置。
2. 在專案資料夾啟動靜態伺服器，例如 `python -m http.server 8000`。
3. 使用瀏覽器開啟 `http://localhost:8000`。
4. 選擇抽牌來源與方式，按 **DRAW ONE** 抽一張，或 **Draw Three** 抽三張。
5. 遇到喜歡的詞，可收藏單詞、這次抽出的牌組，或整個分類。

題庫以 JSON 載入，因此請透過 localhost 或 GitHub Pages 開啟，不要直接使用 `file://`。瀏覽器需支援 `<dialog>` 與 `localStorage`。

## 抽題與分類

首頁提供三種抽牌來源與兩種抽牌方式：

| 來源 | 抽題範圍 |
| --- | --- |
| 全部詞彙 | 符合目前分類設定的詞彙 |
| ★ 最愛題目 | 已個別加入最愛、且符合分類設定的詞彙 |
| ☆ 收藏分類 | 已收藏分類中的詞彙，再依分類設定篩選 |

**完全隨機**會將目前可用的詞彙混合，每個詞都有相同機率。**分類平衡**會先等機率選分類，再從該分類抽詞。抽三張時可勾選「分別來自不同分類」；若可用分類不足三類，就抽出可用的分類數量。同次抽牌不重複抽出同一個詞。

不同次抽牌仍可能抽到相同詞。「從最愛抽今天題目」會在每次點擊時重新隨機抽取，並非每日固定一題。收藏分類也能直接從「我的收藏 → 收藏分類」抽牌，不必先將其中每個詞加入最愛。

在 **Deck Settings** 中調整 21 個詞彙分類，設定會自動保存，並套用到所有抽牌來源。一般 17 類預設開啟；季節分類依月份自動預選：12、1、2 月為冬，3–5 月為春，6–8 月為夏，9–11 月為秋。跨季時自動切換四季分類；同一季內手動變更會保留。

物品、情緒、顏色、場所、天氣、感官、自然、動作、時間、形狀與材質、食物、服飾、動物、植物、職業、交通工具、抽象概念，以及春日、夏日、秋日、冬日風物詩。

介面會顯示目前可抽的詞數。若已收藏詞彙卻無法抽出，可先檢查分類是否開啟。

## 三種收藏

| 類型 | 如何收藏 | 收藏後可以做什麼 |
| --- | --- | --- |
| 最愛詞彙 | 按單張卡片上的「☆ 加入最愛」，或分類預覽中的單題星星 | 查看詞彙、前往來源分類、從最愛再次抽牌 |
| 收藏牌組 | 按所有卡片下方的「☆ 收藏本次牌組」 | 保存這次一起抽出的組合，點擊整列或「展開牌組」回到牌桌查看 |
| 收藏分類 | 點卡片上的分類名稱，再按「☆ 收藏此分類」 | 查看分類詞彙，並從收藏分類中抽牌 |

三種收藏互相獨立。收藏整個牌組或分類，不會自動將其中的詞加入最愛；取消其中一種收藏，也不會移除其他種類的收藏。

**我的收藏** 提供三個分頁，採用一致的清單樣式。收藏牌組以羅馬數字直向排列詞彙，右側星號可取消整組收藏；取消後可按「復原」恢復最近一次取消的牌組，重新整理頁面後不保留這個復原操作。

分類預覽會列出該類所有詞彙。除了點擊卡片來源，也可以從 **Deck Settings → 瀏覽詞彙分類** 開啟。

## 抽卡紀錄與資料保存

**Word Archive** 依日期整理最近 **365 天**的抽牌紀錄，可重新查看當次抽牌。開啟既有紀錄或收藏牌組，不會新增一次抽卡紀錄。

- 最愛詞彙、收藏牌組與收藏分類不受一年期限限制。
- **Clear history** 只清除抽卡紀錄，三種收藏與分類設定都會保留。
- 紀錄、收藏與設定存放在目前瀏覽器的 `localStorage`，不會由程式上傳或跨裝置同步。
- 清除瀏覽器網站資料會移除收藏；換瀏覽器、搬移本機 HTML，或改用不同網址時，不一定能讀到原有資料。
- 目前沒有匯出、匯入或雲端備份功能；「收藏」代表保存在瀏覽器內，不是下載檔案。
- 儲存失敗時會提示，避免將未成功保存的操作顯示為已完成。

### 舊版資料相容

新版使用 `creativeArcana.library.v3` 儲存資料。尚無新版資料時，會讀取同一儲存位置中的 `creativeArcana.history.v2`，承接仍存在的紀錄與牌組收藏，並於下一次成功儲存時寫入新版資料；原本的舊版資料不會被覆寫。

若原有資料無法讀取，程式會暫停儲存，避免覆蓋既有收藏。已被舊版刪除的過期紀錄無法恢復。

## 題庫

正式題庫是 `everyday_prompt_bank_v3_zh_tw.json`，含 **21 個分類、840 個不重複詞彙**。V3 保留 V2 原有 17 類及 720 詞，新增四季風物詩各 30 詞。天空背景圖 `skyloom-sky.jpg` 由 Engin Akyurt 拍攝，依 Unsplash License 使用；頁尾附照片與授權連結。

## 專案結構

```text
.
├── index.html                 # 頁面、彈窗與關於題庫
├── style.css                  # 天空色系、卡片、收藏清單與響應式樣式
├── app.js                     # JSON 載入、抽牌互動與收藏介面
├── arcana-store.js            # 儲存、分類篩選與兩種抽樣規則
├── everyday_prompt_bank_v3_zh_tw.json # 21 類、840 個詞彙
├── README.md
└── tests/
    └── arcana-store.test.js    # 資料與抽題邏輯測試
```

執行網站需要以上檔案，請保持在同一層目錄。沒有額外建置步驟，也不需要 `npm install`。

## 發布到 GitHub Pages

1. 將上述專案檔案上傳至 GitHub repository 根目錄，確認 `index.html` 不在額外的子資料夾內。
2. 進入 repository 的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
4. 選擇檔案所在分支（例如 `main`）與 **/(root)**，按下 **Save**。
5. 等待部署完成，從 Pages 設定頁取得網站網址。

後續更新同一發布分支的檔案，就會觸發網站更新。詳細設定可參考 [GitHub Pages 官方文件](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

本機檔案與 GitHub Pages 是不同的儲存位置，本機使用時的收藏不會自動搬到線上版本。

## 開發與檢查

測試使用 Node.js 內建測試工具，無須第三方測試套件。可使用 Node.js 22 執行：

```sh
node --check app.js
node --check arcana-store.js
node --test tests/arcana-store.test.js
```

目前有 18 項邏輯測試，涵蓋舊收藏承接、分類遷移、四季月份預設、三種收藏獨立性、分類篩選、隨機抽樣、分類平衡、異類抽取、840 個唯一詞彙與儲存失敗。

瀏覽器手動驗收流程：

1. 分別以完全隨機、分類平衡抽三張，確認「分別來自不同分類」可用。
2. 在「我的收藏」確認三個分頁各自顯示正確內容。
3. 分別從最愛詞彙與收藏分類抽牌，並切換分類確認可抽詞數與結果。
4. 展開收藏牌組，確認不增加抽卡紀錄；取消牌組收藏後按「復原」。
5. 重新整理，確認收藏與分類設定仍存在。
6. 清除抽卡紀錄，確認三種收藏仍保留。
7. 以手機寬度檢查長題目換行、抽題來源切換與彈窗捲動。

邏輯測試不涵蓋瀏覽器實際渲染與視覺排版。

題庫資料來源為專案中的 `everyday_prompt_bank_v3_zh_tw.json`。
