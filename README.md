# Creative Arcana

**Draw a card. Tell it your way.**  
抽一張牌，用你的方式說完它。

Creative Arcana 是一個塔羅牌風格的創作靈感抽題工具，適合寫作、繪畫、漫畫、OC／CP 與各種自由創作。以深色牌桌、舊金色線條和象牙白牌面，陪你抽出今天想寫、想畫的題目。

本版延續 v0.2 的介面，加入單題最愛、牌組收藏、完整題庫收藏，以及從收藏中再次抽題的功能。使用純 HTML、CSS 與 JavaScript，無須安裝套件、建立帳號或啟動後端。

## 開始使用

1. 下載專案並解壓縮，保留檔案的相對位置。
2. 使用瀏覽器開啟 `index.html`。
3. 選擇抽題來源，按 **DRAW ONE** 抽一張，或 **Draw Three** 抽三張。
4. 遇到喜歡的題目，可收藏單題、這次抽出的牌組，或整份來源題庫。

一般使用不需要 Node.js 或 localhost。瀏覽器需支援 `<dialog>` 與 `localStorage`；若限制本機檔案的儲存功能，可改用 GitHub Pages 網址開啟。

## 抽題與分類

首頁提供三種抽題來源：

| 來源 | 抽題範圍 |
| --- | --- |
| 全部題目 | 題庫中符合目前分類設定的題目 |
| ★ 最愛題目 | 已個別加入最愛、且符合分類設定的題目 |
| ☆ 收藏題庫 | 合併所有已收藏題庫的完整題目，再依分類設定篩選 |

三種來源都能抽一張或三張。同次抽牌不重複抽出同一道題目；若可用題目不足三題，就抽出目前可用的數量。不同次抽牌仍可能抽到相同題目。

「從最愛抽今天題目」會在每次點擊時重新隨機抽題，並非每日固定一題。收藏題庫也能直接從「我的收藏 → 收藏題庫」按鈕抽一張，不必先將每一道題目加入最愛。

在 **Deck Settings** 中調整分類，設定會自動保存，並套用到所有抽題來源：

| 分類 | 內容方向 | 預設 |
| --- | --- | --- |
| General | 場景、文藝、日常、設定與一般創作題 | 開啟 |
| Romance | 戀愛、關係與親密互動 | 開啟 |
| Dark | 死亡、犯罪、戰爭、末日等沉重題材 | 關閉 |
| Adult | 成人向與明確性內容 | 關閉 |

介面會顯示目前可抽的題數。若已收藏題目卻無法抽出，可先檢查分類是否開啟。

## 三種收藏

| 類型 | 如何收藏 | 收藏後可以做什麼 |
| --- | --- | --- |
| 最愛題目 | 按單張卡片上的「☆ 加入最愛」，或題庫預覽中的單題星星 | 查看題目、前往來源題庫、從最愛再次抽題 |
| 收藏牌組 | 按所有卡片下方的「☆ 收藏本次牌組」 | 保存這次一起抽出的組合，點擊整列或「展開牌組」回到牌桌查看 |
| 收藏題庫 | 點卡片上的題庫名稱，再按「☆ 收藏整份題庫」 | 查看完整清單，並從所有收藏題庫中抽題 |

三種收藏互相獨立。收藏整個牌組或題庫，不會自動將其中的每道題目加入最愛；取消其中一種收藏，也不會移除其他種類的收藏。

**我的收藏** 提供三個分頁，採用一致的清單樣式。收藏牌組以羅馬數字直向排列題目，右側金星可取消整組收藏；取消後可按「復原」恢復最近一次取消的牌組，重新整理頁面後不保留這個復原操作。

題庫預覽會依實際內容顯示題數，不限三十題。除了點擊卡片來源，也可以從 **Deck Settings → 瀏覽完整題庫** 開啟。

## 抽卡紀錄與資料保存

**Arcana Archive** 依日期整理最近 **365 天**的抽卡紀錄，可重新查看當次抽牌。開啟既有紀錄或收藏牌組，不會新增一次抽卡紀錄。

- 最愛題目、收藏牌組與收藏題庫不受一年期限限制。
- **Clear history** 只清除抽卡紀錄，三種收藏與分類設定都會保留。
- 紀錄、收藏與設定存放在目前瀏覽器的 `localStorage`，不會由程式上傳或跨裝置同步。
- 清除瀏覽器網站資料會移除收藏；換瀏覽器、搬移本機 HTML，或改用不同網址時，不一定能讀到原有資料。
- 目前沒有匯出、匯入或雲端備份功能；「收藏」代表保存在瀏覽器內，不是下載檔案。
- 儲存失敗時會提示，避免將未成功保存的操作顯示為已完成。

### 舊版資料相容

新版使用 `creativeArcana.library.v3` 儲存資料。尚無新版資料時，會讀取同一儲存位置中的 `creativeArcana.history.v2`，承接仍存在的紀錄與牌組收藏，並於下一次成功儲存時寫入新版資料；原本的舊版資料不會被覆寫。

若原有資料無法讀取，程式會暫停儲存，避免覆蓋既有收藏。已被舊版刪除的過期紀錄無法恢復。

## 題庫

目前包含 **173 組題庫、5,325 道題目**，資料放在 `prompts.js`。

| 分類 | 題目數 |
| --- | ---: |
| General | 3,422 |
| Romance | 678 |
| Dark | 719 |
| Adult | 506 |

分類以原有題組標題判斷為基礎，已手動調整以下題庫，其餘仍待校對：

- **Dark**：調教戲三十題、陰暗三十題、陰暗關係三十題、負面特質三十題。
- **Adult**：肉梗五十題、清肉湯三十題、H三十題、H三十題-2、做愛時突發狀況十五+五題、癡漢三十題。

既有收藏在抽題時也會套用最新的題庫分類，收藏內容仍會保留。

## 專案結構

```text
.
├── index.html                 # 頁面、彈窗與 Special Thanks
├── style.css                  # 牌桌、卡片、收藏清單與響應式樣式
├── app.js                     # 抽牌互動、收藏介面與題庫預覽
├── arcana-store.js            # 儲存、舊版資料承接、抽題池與隨機抽樣
├── prompts.js                 # 完整題庫資料
├── README.md
└── tests/
    └── arcana-store.test.js    # 資料與抽題邏輯測試
```

執行網站需要前五個檔案，請保持在同一層目錄。沒有額外建置步驟，也不需要 `npm install`。

## 發布到 GitHub Pages

1. 將上述專案檔案上傳至 GitHub repository 根目錄，確認 `index.html` 不在額外的子資料夾內。
2. 進入 repository 的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
4. 選擇檔案所在分支（例如 `main`）與 **/(root)**，按下 **Save**。
5. 等待部署完成，從 Pages 設定頁取得網站網址。

後續更新同一發布分支的檔案，就會觸發網站更新。詳細設定可參考 [GitHub Pages 官方文件](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

本機檔案與 GitHub Pages 是不同的儲存位置，本機使用時的收藏不會自動搬到線上版本。

## 開發與檢查

測試使用 Node.js 內建測試工具，無須第三方測試套件。可使用 Node.js 22 執行：

```sh
node --check app.js
node --check arcana-store.js
node --test tests/arcana-store.test.js
```

目前有 15 項邏輯測試，涵蓋舊收藏承接、三種收藏獨立性、重新載入、清除紀錄、分類篩選、舊收藏套用新分類、收藏題庫抽牌、不重複抽樣、題庫相容性與儲存失敗。

瀏覽器手動驗收流程：

1. 抽三張牌，收藏其中一題、整個牌組與其中一份來源題庫。
2. 在「我的收藏」確認三個分頁各自顯示正確內容。
3. 分別從最愛題目與收藏題庫抽牌，並切換分類確認題數與結果。
4. 展開收藏牌組，確認不增加抽卡紀錄；取消牌組收藏後按「復原」。
5. 重新整理，確認收藏與分類設定仍存在。
6. 清除抽卡紀錄，確認三種收藏仍保留。
7. 以手機寬度檢查長題目換行、抽題來源切換與彈窗捲動。

邏輯測試不涵蓋瀏覽器實際渲染與視覺排版。
